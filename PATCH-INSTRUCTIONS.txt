PATCH TCO TOYOTA — GR MERCHANDISE
=================================

Isi paket:
- merchandise-data.js : master data kategori, produk, harga, warna, material, Part Number.
- merchandise.js      : menambahkan menu desktop/mobile dan section Merchandise otomatis.
- merchandise.css     : tampilan GR dark/red, responsif.
- assets/merchandise/ : gambar halaman produk yang diekstrak langsung dari PDF GR Apparel & Merchandise Catalog.

CARA PASANG
1. Upload folder assets/merchandise/ ke root repository TCO Toyota, sehingga path menjadi:
   assets/merchandise/polo-shirt.png, t-shirt.png, shirt.png, hoodie.png,
   light-jacket.png, gazoo-jacket.png, umbrella.png, cap.png, gears.png.
2. Upload merchandise-data.js, merchandise.js, merchandise.css ke root repository.
3. Buka index.html. Di bagian paling bawah, cari:
      <script src="data.js"></script>
      <script src="app.js"></script>
   Tambahkan dua baris berikut tepat setelah app.js:
      <script src="merchandise-data.js"></script>
      <script src="merchandise.js"></script>
4. Pastikan file gambar di assets/merchandise menggunakan ekstensi .png.
5. Simpan dan deploy. Tidak perlu mengubah detail.html, detail.js, data.js, atau data/units.

CATATAN DATA
- Harga disimpan sebagai angka Rupiah dan ditampilkan dengan format Indonesia.
- Part Number ditampilkan di panel "Ukuran & Part Number".
- Untuk beberapa produk, katalog PDF tidak memberi pemetaan Part Number per warna/ukuran secara lengkap di teks ekstraksi. Data yang belum tersedia tidak dikarang.
- Foto kategori adalah crop halaman katalog PDF asli (bukan foto hasil pencarian internet).
- Halaman 16 berisi GR Places availability, bukan daftar stok cabang live. Ketersediaan aktual tidak ditampilkan sebagai stok realtime.
- Harap verifikasi kembali SKU yang tampak samar pada tabel scan PDF sebelum dipakai sebagai acuan pemesanan.

PERUBAHAN UI
- Menu Merchandise ditambahkan setelah Katalog pada navbar desktop dan mobile.
- Section Merchandise muncul tepat setelah section Katalog.
- Hero progress ditambah item Merchandise; label Hubungi Kami berubah menjadi 04.
- Katalog 17 unit dan halaman detail kendaraan tidak diubah.
